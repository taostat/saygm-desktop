# Bundled font notices

These typefaces are loaded locally by `src/styles/fonts.css`. Their Fontsource packages are
version-pinned in `package.json`; the full SIL Open Font License 1.1 text and copyright
notices are included in the matching files in this directory.

| Font | Package | Copyright |
| --- | --- | --- |
| Onest Variable | `@fontsource-variable/onest` 5.3.1 | The Onest Project Authors |
| Geist Mono Variable | `@fontsource-variable/geist-mono` 5.3.0 | The Geist Project Authors |
| Instrument Serif | `@fontsource/instrument-serif` 5.3.0 | The Instrument Serif Project Authors |
